Локальная среда тестов: Python 3.10, CPU/macOS ARM64; PyTorch 2.14.0, torchvision 0.29.0, NumPy 1.26.4, Ultralytics 8.4.150, pycocotools 2.0.11, torch-fidelity 0.4.0. `pip check` не выявил конфликтов после согласования зависимостей в локальной .venv. В исходных установленных системных пакетах изменений не делалось.

Результат общей проверки 13.09.2026: **31 тест пройден**, ошибок и пропусков нет (20.740 с). Проверка включает все 12 исходных SHA-256, 33 ID, маленький сквозной fixture → manifest → model → prediction → metric, а также восстановление LSTM в отдельном процессе. Это время тестов, не оценка времени обучения.

Тестовые данные существуют только во временных каталогах. Данные курса, начальные веса и Inception-веса не скачивались. Ни команды smoke/train, ни итоговые PDF в этом цикле не запускались. Синтетические FID/IS считаются на искусственных признаках/вероятностях и не подменяют финальные метрики.
